# ERP Simulator

An interactive, browser-based ERP Logistics Case Study Simulator covering Materials Management (MM), Production Planning (PP), and Sales & Distribution (SD) modules.

## Features
- 54-step guided simulation with pre-filled default values
- End-to-End Business Flow Explorer (interactive pipeline visualizer)
- Offline Excel template download
- Persistent progress saved to browser local storage
- Light / Dark mode toggle

## Live Demo
🔗 Hosted on GitHub Pages

## How to Use
Open `index.html` in any modern browser. No build step or server required.
